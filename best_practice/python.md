# Лучшие практики для программиста Python (актуально для 3.13.5)

## 0. Новое в Python 3.13

- **Новый интерактивный REPL**: поддержка редактирования блоков, цветные подсказки, улучшенная история, paste mode, команды `help`, `exit`, `quit` без скобок.
- **Улучшенные сообщения об ошибках**: цветные traceback-и, более понятные подсказки при опечатках и ошибках импорта.
- **Оптимизация памяти**: списки и словари занимают меньше памяти (до -20%).
- **Быстрее стандартные операции**: адаптивный интерпретатор ускоряет часто вызываемые функции (до 30% быстрее в некоторых случаях).
- **Расширенное pattern matching**: проще сопоставлять типы, значения, части последовательностей.
- **Типизация**: поддержка дефолтных значений для type parameters, улучшения в подсказках типов.
- **Удалены устаревшие модули**: см. [PEP 594](https://peps.python.org/pep-0594/).
- **`locals()`** теперь имеет чётко определённую семантику.

## 1. Стиль кода и читаемость

- Следуйте PEP 8: 4 пробела, snake_case, длина строки до 79 символов.
- Используйте осмысленные имена переменных, функций и классов.
- Пишите docstring-и для функций, классов и модулей.
- Разделяйте логические блоки пустыми строками.
- Импортируйте только необходимые объекты:
  ```python
  from subprocess import Popen, PIPE
  ```
- Сначала пишите docstring, затем импорты, затем код.

## 2. Структура модулей и организация кода

- Основную логику помещайте в функцию `main()` и вызывайте её через:
  ```python
  if __name__ == '__main__':
      main()
  ```
- Используйте абсолютные импорты, избегайте относительных без необходимости.
- Группируйте импорты: стандартная библиотека, сторонние, локальные.

## 3. Обработка ошибок

- Ловите только ожидаемые исключения:
  ```python
  try:
      import foo
  except ImportError:
      foo = None
  ```
- Не используйте пустой `except:` — это ловит системные ошибки.
- Минимизируйте область try-блока:
  ```python
  try:
      value = d[key]
  except KeyError:
      handle_missing()
  else:
      process(value)
  ```
- Используйте явное связывание исключений (`raise ... from ...`).
- Используйте `dict.get()` для безопасного доступа к значениям:
  ```python
  city = data.get("city", "Unknown")
  ```

## 4. Безопасность

- Не используйте `eval()` на недоверенных данных.
- Для SQL — только параметризованные запросы:
  ```python
  cursor.execute('SELECT * FROM users WHERE id=?', (user_id,))
  ```
- Для временных файлов используйте:
  ```python
  import tempfile
  with tempfile.TemporaryDirectory() as tmpdir:
      ...
  ```
- Для криптографии используйте стандартные модули (`secrets`, `hashlib`, `hmac`).
- Для работы с SSL/TLS используйте `ssl.create_default_context()`.
- Не используйте `shell=True` в `subprocess`, если не требуется. Если требуется — экранируйте аргументы через `shlex.quote`.
- Не храните секреты и пароли в коде — используйте переменные окружения или файлы `.env`.
- Проверяйте входные данные, особенно если они поступают из внешних источников.
- Для сравнения синглтонов (`None`, `NotImplemented`) используйте `is`/`is not`.

## 5. Работа с зависимостями

- Указывайте только реально используемые зависимости.
- Используйте виртуальные окружения (`venv`, `virtualenv`).
- Для управления зависимостями используйте `requirements.txt` или `pyproject.toml`.

## 6. Аннотации типов и документация

- Используйте аннотации типов для функций и переменных:
  ```python
  def add(x: int, y: int) -> int:
      return x + y
  ```
- Для сложных типов используйте `typing`:
  ```python
  from typing import List, Dict
  def process(items: List[str]) -> Dict[str, int]:
      ...
  ```
- Для получения аннотаций используйте `inspect.get_annotations()` (Python 3.10+).
- Используйте docstring-и для описания назначения и параметров функций.

## 7. Идиоматичность и производительность

- Используйте генераторы и списковые включения вместо циклов, где это уместно:
  ```python
  squares = [x*x for x in range(10)]
  ```
- Для итерации по коллекциям используйте прямой перебор:
  ```python
  for item in items:
      ...
  ```
- Не используйте лямбда-функции для присваивания переменных — используйте `def`.
- Для работы с несколькими файлами используйте `contextlib.ExitStack()`:
  ```python
  from contextlib import ExitStack
  with ExitStack() as stack:
      f1 = stack.enter_context(open('file1'))
      f2 = stack.enter_context(open('file2'))
  ```
- Для больших данных используйте NumPy/Pandas и векторные операции.
- Профилируйте код (`cProfile`, `timeit`) для поиска узких мест.

## 8. Работа с файлами и ресурсами

- Используйте контекстные менеджеры (`with`) для работы с файлами и ресурсами:
  ```python
  with open('file.txt') as f:
      data = f.read()
  ```
- Не забывайте закрывать ресурсы — контекстные менеджеры делают это автоматически.

## 9. Тестирование

- Пишите модульные тесты для ключевых функций.
- Используйте стандартный модуль `unittest` или сторонние (`pytest`).
- Автоматизируйте запуск тестов.

## 10. Современные конструкции языка (Python 3.13)

- Используйте pattern matching (`match-case`) для чистых ветвлений по типу/значению:
  ```python
  def describe_type(obj):
      match obj:
          case str():
              return "Строка"
          case int():
              return "Целое число"
          case list():
              return "Список"
          case _:
              return "Что-то ещё"
  ```
- Используйте новые возможности REPL для интерактивной работы и отладки.
- Используйте цветные traceback-и для быстрого поиска ошибок.
